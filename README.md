## Notes
- **Buy the PC version.** The Xbox & PC R3 bundle costs about $60 more and won't fit this budget.
- **The clutch must be the SR-P *Lite* one.** The regular SR-P clutch doesn't fit the R3's SR-P Lite pedals.
- **Handbrake mount:** the cockpit has one shifter mount. To mount the handbrake next to the shifter, add a universal shifter/handbrake bracket (LGIB, Minneer) for about $20–25. If that puts you over budget, the **refurbished** R3 PC bundle is $199 from [Moza's store](https://us.mozaracing.com/collections/r3-bundles).
- **Sturdiness:** foldable cockpits start to flex above about 10 Nm. The R3 runs at 3.9 Nm, so this cockpit is fine.
- **The generic shifter and handbrake** show up as separate USB controllers. Bind them in each game (Assetto Corsa, BeamNG, DiRT/WRC, ETS2/ATS, etc.). Quality varies by seller, so pick listings with a lot of recent reviews.
